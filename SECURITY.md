# Security reports

Report vulnerabilities privately through [GitHub security advisories](https://github.com/Afnanksalal/hell-let-loose/security/advisories/new). Include the affected commit, impact and reproduction steps. Do not post credentials or exploitable details in a public issue.

The project is in pre-production and has no supported game release yet. Ordinary documentation defects belong in Issues. Supported versions and security update expectations will be documented before playable distribution.
