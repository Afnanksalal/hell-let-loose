# Open questions and risks

| Topic | Unresolved |
| --- | --- |
| Battles | Format, turns, idle players, encounter transitions and eight-player waiting |
| Customization | Launch dimensions, layering, animation compatibility and cosmetic versus power effects |
| Powers | Predictability, combinations, temporary effects and reset rules |
| Story | Canon, party choices, branching scope and tolerance for mischief |
| Tone | Feel-good slapstick versus horror, audience and rating |
| Narration | Voice, personality, frequency, branching and localization |
| Aging | Triggers, mixed-age parties and what forgetting changes mechanically |
| Generations | First-game versus sequel placement and inherited/account state |
| Production | Team, budget, camera, engine, platform and first deliverable |
| Title | Final publishing name; existing-name conflict was raised in the source chats |

Earlier risks: daytime becomes a chore, night gets repetitive, event flags contradict, network state diverges, eight-player effects become unreadable, campaign ownership confuses progression and session pacing becomes rushed.

Massive customization multiplies art combinations; aging multiplies stages; branching stories multiply writing. These issues need planning rather than silently shrinking the vision or promising an unsupported date. Proposed mitigations include consequential daytime stories, distinct incidents, authored dependencies, authoritative state, readable silhouettes and reusable content systems.
