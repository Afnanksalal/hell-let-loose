# Daytime life and household stealth

Make daytime choices, parental supervision and the escape produce consequences for the night.

[Epic #13](https://github.com/Afnanksalal/hell-let-loose/issues/13) · [Design](../../docs/gameplay/daytime-and-stealth.md)

## Work items

### Define daytime behavior-to-power rules

[Issue #4](https://github.com/Afnanksalal/hell-let-loose/issues/4) · P1 · G1

- [ ] Define discovery, duration, stacking and reset behavior for daytime effects.
- [ ] Provide three draft powers with tactical choices and comic consequences.
- [ ] Separate illustrative move ideas from accepted balance values.

### Prototype baby needs as meaningful daytime choices

[Issue #24](https://github.com/Afnanksalal/hell-let-loose/issues/24) · P1 · G1

- [ ] Select the initial needs and explain each gameplay consequence.
- [ ] Demonstrate feeding, rest or comfort affecting preparation without repeated mandatory chores.
- [ ] Provide readable feedback and recovery for an adverse need state.
- [ ] Record playtest observations about interruption frequency and daytime enjoyment.

Depends on: [#21](https://github.com/Afnanksalal/hell-let-loose/issues/21), [#20](https://github.com/Afnanksalal/hell-let-loose/issues/20).

### Implement parent routines and household suspicion

[Issue #25](https://github.com/Afnanksalal/hell-let-loose/issues/25) · P1 · G1

- [ ] Implement a readable parent routine with at least one response to noise or missing objects.
- [ ] Define suspicion causes, recovery and persistence between phases.
- [ ] Show a daytime mistake changing the same household at sunset.
- [ ] Verify a player can understand why supervision changed without hidden arbitrary punishment.

Depends on: [#21](https://github.com/Afnanksalal/hell-let-loose/issues/21), [#20](https://github.com/Afnanksalal/hell-let-loose/issues/20).

### Build cooperative crib escape and dawn return

[Issue #26](https://github.com/Afnanksalal/hell-let-loose/issues/26) · P1 · G1

- [ ] Provide a short escape with hiding or distraction and a way for a free teammate to help.
- [ ] Carry an escape complication from daytime state.
- [ ] Implement detected and undetected returns with different next-day consequences.
- [ ] Keep the return playable after the nighttime objective is complete.

Depends on: [#25](https://github.com/Afnanksalal/hell-let-loose/issues/25), [#20](https://github.com/Afnanksalal/hell-let-loose/issues/20).

### Connect one daytime behavior to a nighttime power

[Issue #27](https://github.com/Afnanksalal/hell-let-loose/issues/27) · P1 · G1

- [ ] Implement one accepted behavior effect with visible acquisition and expiration rules.
- [ ] Make the effect useful in a battle rather than only a visual joke.
- [ ] Verify behavior effects survive the sunset transition and reset or persist as specified.
- [ ] Document the tuning values as prototype values rather than permanent balance commitments.

Depends on: [#4](https://github.com/Afnanksalal/hell-let-loose/issues/4), [#22](https://github.com/Afnanksalal/hell-let-loose/issues/22), [#31](https://github.com/Afnanksalal/hell-let-loose/issues/31).
