# Implementation plan

Godot is selected. Runtime implementation has not started. This plan breaks the design into tracked work; a future gate does not imply its features are already implemented.

The [Project](https://github.com/users/Afnanksalal/projects/3) holds live status. Each epic below links its native child issues, design context, dependencies and acceptance criteria.

| Epic | Scope | Gate |
| --- | --- | --- |
| [Godot project foundation](epics/godot.md) | Establish a reproducible Godot project and the shared runtime boundaries needed by the prototype. | G1 |
| [Daytime life and household stealth](epics/household.md) | Make daytime choices, parental supervision and the escape produce consequences for the night. | G1 |
| [Cooperative battle system](epics/battle.md) | Choose and demonstrate a tactical battle format that keeps small and large parties involved. | G1 |
| [Character identity and art pipeline](epics/identity.md) | Support expressive original characters and compatible customization before expanding the wardrobe. | G2 |
| [Neighborhood story and narration](epics/story.md) | Deliver one authored incident across day, night and the next morning, with meaningful branches and narration. | G2 |
| [Multiplayer authority and campaign saves](epics/online.md) | Keep actions and consequences consistent across clients and recover progress after interruption. | G1 |
| [Progression, memory and generations](epics/generation.md) | Define and implement progression toward adulthood without losing the meaning of character identity. | G3 |
| [Playtesting and release readiness](epics/release.md) | Progress from a complete vertical slice to a supported build through inspectable test and distribution evidence. | G5 |
