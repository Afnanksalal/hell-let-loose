# Assets

Original production assets belong here. No artwork, audio or third-party packs have been added yet.

| Directory | Contents |
| --- | --- |
| [characters](characters/README.md) | Character designs, animation and customization parts |
| [environments](environments/README.md) | Household, neighborhood and supernatural environment art |
| [ui](ui/README.md) | Icons, interface illustration and typography resources |
| [audio](audio/README.md) | Music, narration, ambience and effects |

Record creator, original file, permitted use and attribution for every imported asset in [provenance](provenance.md). Keep editable sources distinct from exports when the production pipeline is chosen. Generated engine caches and build outputs do not belong in version control.

Use Git LFS for production binaries once the asset formats and contributor workflow are established; no LFS patterns are configured before those files exist.
