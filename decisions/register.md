# Design decisions

Accepted direction guides implementation. Open choices require a recorded outcome before code depends on them. Draft names and episodes remain design studies.

| ID | Status | Decision |
| --- | --- | --- |
| D001 | Accepted | Hell Let Loose is the working title; final naming is unresolved. |
| D002 | Accepted | Daytime social care and household mischief connect to secret nighttime demon battles. |
| D003 | Target | Cooperative play for 2 to 8 players; sessions roughly 20 to 30 minutes. |
| D004 | Accepted | Story events respond to player choices rather than a fixed chore list. |
| D005 | Accepted | The campaign reaches adulthood, fading identity and a new generation. |
| D006 | Retired | Pixel-grid art production. |
| D007 | Accepted | Colorful drawn characters with bold outlines and exaggerated acting. |
| D008 | Accepted | Extensive character customization is a central system. |
| D009 | Accepted | Battles emphasize distinct moves, status effects and team tactics. |
| D010 | Open | Battle turn structure and multiplayer action resolution. |
| D011 | Accepted | Comic plots and narration accompany an authored supernatural mystery. |
| D012 | Accepted | Household stealth uses readable routines, distractions and physical comedy. |
| D013 | Accepted | Daytime behavior can produce absurd nighttime powers; individual moves remain drafts. |
| D014 | Draft | Setting names, mythology and chapter outline. |
| D015 | Open | Godot version, renderer, language, camera, networking stack and production scope. |
| D016 | Open | Aging rules, ending and next-generation placement. |
| D017 | Accepted | One repository contains the full game codebase, assets, tests and documentation. |
| D018 | Accepted | Public GitHub repository, issue board, pull-request workflow and release gates. |
| D019 | Open | Hackathon category selection. |
| D020 | Accepted | Public writing describes the game directly without comparison-based branding. |
| D021 | Accepted | All rights reserved; viewing and inspiration do not grant redistribution or sale rights. |
| D022 | Accepted | Standard workflow checks; no standalone repository-check scripts or generated test suite. |

| D023 | Accepted | Godot is the game engine. Exact version, renderer and language will be pinned during project bootstrap. |

## Recording a decision

Link the issue, describe the selected option and its consequences, and update the affected subsystem document. Retain the retired option when its tradeoff helps explain the outcome. A draft does not become accepted because it appears in a file.
