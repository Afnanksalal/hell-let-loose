# 0.1.0: repository foundation

This baseline establishes the game repository, design documentation, project tracking and development workflow.

The repository has space for runtime source, scenes, game data, interface code, original assets and game tests. Markdown and local documentation links are checked in CI. Main uses pull requests and required checks; version tags are protected from rewriting.

There is no playable build in this baseline. Engine selection and the first battle prototype remain open. Later releases require implementation and playtest evidence appropriate to their gate.
