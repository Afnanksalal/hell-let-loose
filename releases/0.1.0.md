# 0.1.0 — Knowledge base foundation

## Scope

Structured design knowledge base with current creative direction, source records, decision register, gameplay/story/art/progression topics, contribution workflow, issue planning and release gates.

## Validation

Repository checker and its regression tests. Public GitHub setup and Project are tracked in the foundation issue. Release workflow must pass at the chosen commit before publication.

## Limitations

This is not a playable game. No engine, finalized battle system or license has been selected. Shared-chat records are summaries, not full transcript exports. G1–G5 remain unpassed.
